BBC Image Backup

Shortcut iPhone tự kiểm tra và chỉ tải ảnh chưa có.

Thông số

Base URL: https://img.binhpro.com

Check: /api/backup/check?assetId=...

Upload: /upload

Header: Authorization: Bearer BACKUP_TOKEN

Chuỗi nhận diện ảnh

v1|Tên ảnh|Dung lượng byte|Ngày chụp milliseconds

Ví dụ: v1|IMG_1234.HEIC|2840193|1784954535000

Cách chạy

  1. Find Photos trong 7 ngày gần nhất.
  2. Repeat with Each.
  3. Tạo Asset ID.
  4. Gọi API check.
  5. Nếu exists=false, gửi form lên /upload.

Không ghi BACKUP_TOKEN vào GitHub hoặc ảnh chụp màn hình công khai.

Xem file HUONG-DAN-SHORTCUT-IPHONE.txt để có đầy đủ từng action.
